## 一句话总结

> 用冻结 DINOv3 的未来 latent 预测取代视频生成，不到 100M 参数即获得强多任务操作性能。

---

## 核心贡献

1. **紧凑 latent WAM**: 以冻结 DINOv3 patch feature 为预测目标，跳过像素级视频生成。
2. **任务条件而非动作条件**: predictor 仅用 task ID 预测近/远两个未来，action decoder 再从当前与未来 token 中回归 action chunk。
3. **规模—性能反例**: 38M/77M 配置在 RoboTwin 2.0 超过当时的 billion-parameter WAM，并在真机上显示更低延迟与更好 closed-loop success。

## 问题背景

### 要解决的问题

[[World Action Model]] 通常把未来视觉预测和机器人动作生成绑在一起。这种设计有两个直观问题：

- video/VLM backbone 往往达到数十亿参数，训练和推理成本高；
- 像素级 future prediction 花费大量容量重建背景、材质和光照，但这些细节未必有助于动作。

本文要验证的命题是：对封闭多任务操作，一个小型的、几何感知的 latent predictor 是否已经足够。

#### 公式 1: [[Latent Prediction|两时域 latent 预测]]

$$
\hat{z}_{t+h_1},\,\hat{z}_{t+h_2}=F(z_t,g_k)
$$

**含义**: predictor $F$ 从当前视觉 token 和任务编码预测两个未来时域。

**符号说明**:
- $z_t$: 时刻 $t$ 的多视角 latent token；
- $g_k$: 第 $k$ 个任务的 learned code；
- $h_1,h_2$: 近期与远期预测时域。

#### 公式 2: [[Action Chunking|动作块回归]]

$$
\hat{a}_{t:t+H}
=D\!\left(z_t,\hat{z}_{t+h_1},\hat{z}_{t+h_2},s_t,g_k\right)
$$

**含义**: action decoder $D$ 不必看视频像素，直接从当前/未来 latent、机器人状态和任务编码生成未来 $H$ 步动作。

**符号说明**:
- $s_t$: proprioceptive robot state；
- $H$: action chunk 长度；
- $\hat{a}_{t:t+H}$: 预测的未来动作序列。

### 现有方法的局限

#### Figure 1: Success rate versus model size

![Figure 1](https://arxiv.org/html/2610.37091v1/model_size_success.svg)

**说明**: 图中同时给出 LIBERO 与 RoboTwin 2.0 的成功率—模型尺寸关系。GAWM-S 位于 RoboTwin 2.0 的小模型/高成功率区域，直接反驳“WAM 必须继承大 video generator”的隐含假设。

### 本文的动机

作者把“预测未来”与“生成未来图像”分开：如果 frozen vision encoder 的 dense patch feature 已保留布局和对象几何，那么 policy 只需预测这个特征未来，无需支付高保真生成的代价。

## 核心技术

### 数据与任务定义

论文使用三类设置：

- [[LIBERO]]: 四个 suite，测试空间、物体、目标和长时程操作；
- [[RoboTwin 2.0]]: clean/randomized 设置，采用 mixed protocol，每个任务 50 条 clean + 500 条 randomized demo；
- 真机双臂拿瓶并放到桌面，任务仅由目标瓶身份区分。

这也暴露了方法的一个边界：它使用 task ID，不是 free-form language instruction。

### 模型架构

GAWM 是一个小型 latent [[World Action Model]]:

- **输入**: 多摄像头 RGB、robot state、task ID；
- **Vision encoder**: 冻结 DINOv3；
- **Query adapter**: 每个视角压缩为 64 个 token；
- **Latent predictor**: 两个未来时域的 token forecast；
- **Patch decoder**: 仅训练期存在，将 forecast 解码到未来 DINOv3 patch feature；
- **Action decoder**: 从当前、近期、远期 forecast 与 state token 中直接回归 action chunk；
- **参数量**: LIBERO 38M，RoboTwin 2.0 77M（表中口径包括推理时从 observation/task 到 action chunk 的模块）。

#### Figure 2: GAWM architecture

![Figure 2](https://arxiv.org/html/2610.37091v1/architecture.png)

**说明**: 图中虚线区域是训练专用 patch decoder。推理时只保留 frozen encoder、query adapter、latent predictor 和 action decoder，因此 future supervision 不导致 online rendering 成本。

#### 公式 3: [[Cross-Attention|视觉 token 适配]]

$$
z=\overline{\operatorname{LN}}\!\big(A(q;U)\big)+e
$$

**含义**: learned query $q$ 通过 cross-attention $A$ 读取 encoder patch feature $U$，再经平均 layer normalization 并加入 camera embedding $e$。

**符号说明**:
- $U$: DINOv3 dense patch feature；
- $q$: adapter learned query；
- $e$: 摄像头/视角 embedding；
- $z$: 压缩后视觉 token。

### 未来 latent predictor

预测器输出两组 readout，通过 residual 方式改写当前 token，而不是从零生成整个未来。这个归纳偏置很合理：短时域 manipulation 中，大部分场景静态，未来应是当前表示的结构化残差。

#### 公式 4: [[Residual Prediction|双时域残差预测]]

$$
\hat{z}_{t+h_j}
=\overline{\operatorname{LN}}\!\left(z_t+W_o r_j\right),
\qquad j\in\{1,2\}
$$

**含义**: 第 $j$ 个 readout $r_j$ 经线性投影后作为当前 token 的 residual，得到近/远未来预测。

**符号说明**:
- $W_o$: readout 投影矩阵；
- $r_j$: 对应 horizon 的 predictor readout；
- $\overline{\operatorname{LN}}$: 论文定义的归一化操作。

### Forecast supervision

未来预测不对 RGB 像素做 MSE，而是对 frozen DINOv3 的 dense future patch feature 做 cosine objective。这将监督重点放在特征方向/结构上，弱化特征模长和像素细节。

#### 公式 5: [[Cosine Similarity|未来特征损失]]

$$
\mathcal{L}_{\mathrm{fut}}
=\mathbb{E}_{j,v,p}\!\left[
1-\cos\!\left(
G(\hat{z}_{t+h_j})_p,
\operatorname{sg}(X_{t+h_j,p})
\right)
\right]
$$

**含义**: patch decoder $G$ 重建未来 patch feature，与冻结 encoder 产生的 target $X$ 最大化 cosine similarity。Stop-gradient 确保 target encoder 不被 policy loss 改写。

**符号说明**:
- $j$: 未来 horizon 索引；
- $v$: camera view 索引；
- $p$: patch 索引；
- $G$: training-only patch decoder；
- $X_{t+h_j,p}$: 未来帧的 frozen encoder patch feature。

#### Figure 4: Decoded forecasts

![Figure 4](https://arxiv.org/html/2610.37091v1/foresight_pca.png)

**说明**: 左侧是 $t,t+16,t+32$ 的 RGB，右侧把真实与预测 DINOv3 patch feature 投影到共享 PCA 基。这些结果不应被解读为“生成了高保真未来”，而是证明 forecast 跟踪了和动作相关的布局变化。

### Action decoder

动作解码器将四类 memory 拼接：当前 visual token、两个未来 forecast、robot-state token 和 task code。不同 action step 通过 action query 对这些 memory 做 cross-attention。

#### 公式 6: 记忆组合与动作输出

$$
\begin{aligned}
M_t
&=\left[z_t;\hat{z}_{t+h_1};\hat{z}_{t+h_2};
\sigma(s_t);W_g g_k\right],\\
\hat{a}_{t:t+H}
&=\tanh\!\left(\operatorname{MLP}
\big(\operatorname{Dec}(q^a;M_t)\big)\right)
\end{aligned}
$$

**含义**: 将所有当前/预测证据组合成 memory，action query $q^a$ 读取后由 MLP 输出归一化动作。

**符号说明**:
- $\sigma(s_t)$: robot state 的 tokenization；
- $W_g g_k$: task code 投影；
- $q^a$: 每个动作步的 query；
- $\operatorname{Dec}$: Transformer decoder。

#### Figure 5: Attention analysis

![Figure 5](https://arxiv.org/html/2610.37091v1/attention.png)

**说明**: 上半部分可视化 adapter 对 image patch 的 cross-attention；下半部分显示 action decoder 在不同 action step 中分配给当前 token、近/远 forecast 和 state token 的注意力份额。这为“forecast 确实被 action decoder 使用”提供了间接证据，但 attention 不等于因果贡献，真正因果证据仍来自表 II ablation。

### 训练方法

#### 公式 7: 总训练目标

$$
\begin{aligned}
\mathcal{L}
={}&\mathcal{L}_{\mathrm{act}}
+\lambda_{\mathrm{fut}}\mathcal{L}_{\mathrm{fut}}
+\lambda_{\mathrm{cur}}\mathcal{L}_{\mathrm{cur}}\\
&+\lambda_{\mathrm{reg}}
\left(\mathcal{L}_{\mathrm{div}}+\mathcal{L}_{\mathrm{var}}\right)
+\lambda_{\mathrm{tmp}}\mathcal{L}_{\mathrm{tmp}}
\end{aligned}
$$

**含义**: 动作回归是主目标，future/current feature reconstruction 形成视觉监督，diversity/variance/temporal 项用于防止 token 退化并保持时序结构。

**符号说明**:
- $\mathcal{L}_{\mathrm{act}}$: action-chunk regression loss；
- $\mathcal{L}_{\mathrm{fut}}$: 公式 5 的未来 patch-feature loss；
- $\mathcal{L}_{\mathrm{cur}}$: 当前帧 feature reconstruction；
- $\mathcal{L}_{\mathrm{div}},\mathcal{L}_{\mathrm{var}}$: token diversity/variance regularization；
- $\mathcal{L}_{\mathrm{tmp}}$: temporal regularization；
- $\lambda_*$: 各损失权重。

### 推理与部署

推理时删除 patch decoder，不保留 RGB generation 或 future-feature decoding。每次 policy query 仅执行 vision encoder、query adapter、latent predictor 和 action decoder。

#### Figure 3: Inference latency per action-chunk query

![Figure 3](https://arxiv.org/html/2610.37091v1/latency.svg)

**说明**: 在同一 NVIDIA RTX PRO 5000、batch size 1、官方默认精度/去噪步数下测量 200 次 query 中位数。GAWM 的优势不仅来自参数少，也来自无迭代生成采样。

## 批判性思考

### 优点

1. 用小模型和明确的 training-only auxiliary target 验证 WAM 核心价值，而不是把整个 video generator 当黑箱。
2. 表 II 真正删除 world-model objective，且在不同数据/训练预算下测试，因果证据比单一 leaderboard 更好。
3. 仿真主结果、真机 closed loop、延迟和 feature/attention 可视化形成了相对完整的证据链。

### 局限性

1. task input 是 ID 而不是语言，与 VLA 的 open-vocabulary 泛化目标不同；小模型优势部分来自问题范围更窄。
2. 真机 closed-loop success 仅在 yellow-bottle task 上对比，其他三个目标及分布外变化未见同等证据。
3. latent predictor 不显式条件化候选 action，所以它不能直接用于反事实 planning 或 action selection；“world-action model”的含义比 action-conditioned simulator 更弱。

### 潜在改进方向

1. 将 task ID 换成语言/视觉目标表示，检查紧凑 latent predictor 在 compositional instruction 下是否仍然有效。
2. 加入 action-conditioned branch，用同一 latent forecast 做候选 action 排序，以区分“表征正则化”和“可规划 world model”。
3. 在更多真机任务、相机偏移、对象置换和长时程失败下评估，同时报告 predictor collapse 与 forecast error 的失败案例。
