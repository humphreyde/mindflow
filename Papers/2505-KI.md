## 一句话总结

> 同一个 VLA 同时用**离散动作 token 的 cross-entropy** 训 VLM backbone、用 **flow-matching action expert** 出连续动作，并把 action expert 的梯度 **stop-gradient** 隔在 backbone 之外——训练快、推理快、语言遵循也最强。

---

## 核心贡献

1. **联合离散+连续动作建模 (Joint discrete/continuous action prediction)**: 同一个 VLA 同时学**自回归 [[FAST Token|FAST 离散动作]] 预测**（给 VLM backbone 提供学习信号）和 **flow-matching 连续动作预测**（给 [[Action Expert]] 用），训练时两路 loss 加权相加，推理时只跑 action expert，兼得**训练快**与**推理快**。
2. **Knowledge Insulation 知识隔离**: 用 **[[Stop Gradient|stop-gradient]]** 阻断 action expert 到 VLM backbone 的反向梯度传播。VLM 只能"被读"不会被 action expert 的高方差噪声污染，但仍能从离散 [[FAST Token]] 监督和 [[Co-training|VLM data co-training]] 中学到机器人相关 representation。
3. **VLM data co-training**: 把图像描述、VQA、bounding box 预测等通用 VLM 任务和机器人动作数据混在同一 batch 里 co-train，让 VLA 不丢失预训练知识，**显著改善 [[Language Following|语言遵循能力]]** 和对未见物体的泛化。
4. **修改后的 [[Blockwise Attention Mask|分块注意力]]**: backbone tokens 不能 attend action-expert tokens（单向信息流：VLM → action expert）；同时 FAST 离散动作 token 与 flow-matching 连续动作 token **互相不可见**，避免两路动作表示信息泄漏。
5. **实证证据**: 在 7 个真实操作任务（含静态单臂/双臂、移动双臂）+ LIBERO + DROID 上，本方法比 [[Pi0]] 快 7.5× 收敛、推理与 [[Pi0]]-FAST 相当快但语言遵循更强；在 LIBERO-90 / LIBERO-Spatial 上达到 SOTA。

## 问题背景

### 要解决的问题

[[VLA]] 的设计存在三难：

- **训练快**：用 [[FAST Token|FAST 离散动作]] + autoregressive cross-entropy 训练收敛快，但推理慢。
- **推理快**：用小 [[Action Expert]] + [[Flow Matching]] 出连续动作（[[Pi0]] 范式）推理快，但训练慢、且把 action expert 的梯度回传到 VLM 会**腐蚀**预训练知识，导致[[Language Following|语言遵循]]变差。
- **泛化强**：要保留 VLM 预训练的世界知识，就需要 [[Co-training|VLM data co-training]]，但传统 [[Pi0]] 架构无法干净地在同一个 transformer 里混训不同模态。

### 现有方法的局限

论文 Sec 4（见 Figure 2）总结四类典型失败：

1. **[[Pi0]]**：忽略语言指令（被指示"把勺子放进 bin"，却收拾别的东西）。
2. **[[Pi0-FAST]]**：自回归解码慢（RTX4090 上预测 1 秒动作 chunk 需 ≈ 750 ms），动力学不匹配。
3. **frozen backbone**：直接 freeze VLM 又不够灵活，机器人 specific representation 学不出来。
4. **naive joint-training（无 stop-gradient）**：action expert 的梯度会污染 VLM，[[Language Following|语言遵循率]]显著下降。

### 本文的动机

如果把 VLM 当成一个**良好的 representation 提供者**：

- 用**稳定**的离散 token 监督（[[FAST Token]] 的 cross-entropy）只更新 VLM weights；
- 让 [[Action Expert]] 跨 attention 读 VLM 表示，但 **[[Stop Gradient|梯度不回传]]**；
- 同时混入 [[Co-training|VLM 通用数据]] 巩固预训练知识；

就能同时拿到训练快（离散监督收敛快）、推理快（小 action expert + flow matching）、泛化强（VLM 知识不被破坏）。

## 方法详解

### 模型架构

KI 在 [[Pi0]] 的 Mixture-of-Experts 框架基础上扩展：

- **输入**: 图像 $I_{1:V}$ + 本体感受状态 $q$ + 语言指令 $\ell$ → 多模态 token 序列 $x_{1:n}$。
- **Backbone**: [[PaliGemma]] 2B（width 2048, depth 18, 18 heads, 1 KV head）。
- **[[Action Expert]]**: 与 backbone 相同 depth 但更窄（width 1024, mlp_dim 4096），共 300M 参数；用 [[Adaptive RMSNorm]] 注入 flow-matching timestep $\tau$，$\tau$ 经 [[Sinusoidal Positional Encoding|sinusoidal]] + 双层 swish MLP。
- **输出**: 同时 $y = (a_{1:H}, y^{\ell, a})$，其中 $a_{1:H}$ 是 [[Action Chunking|连续动作 chunk]]（$H=50$），$y^{\ell, a}$ 是离散文本 token + [[FAST Token]] 离散动作 token。
- **总参数**: VLM 2B + action expert 300M ≈ 2.3B。

不同模态走**不同 expert** ：图像 patch / 文本 / FAST 动作 token / state → backbone weights；noisy 连续动作 → action expert weights。两侧只通过 attention 交互，**互相独立的 Q/K/V projection** 但共享 $d_q, d_k, d_v$ 维度。

### 核心模块

#### 模块 1: Joint discrete/continuous action prediction（[[Co-training]]+representation learning）

**设计动机**：用稳定的离散监督让 VLM 习得机器人 representation，同时用 flow-matching 出高分辨率连续动作。

**具体实现**：
- 同一个动作 chunk $a_{1:H}$ 有两份 label：连续浮点向量（给 flow matching）和 [[FAST Token|FAST 离散 token]]（给 cross-entropy）。
- 把这两路 loss 加权相加得到 $\mathcal{L}_{\text{CO-VLA}}$（公式 4）。
- 加 mask 控制：[[Naive Action Tokenization|FAST 离散动作 token]] 与 [[Continuous Action Token|连续动作 token]] **互相不可 attend**，防止"答案泄漏"。
- 数据混合 mask $M^{\text{act}}$ 决定该样本是否做动作预测，因此可同时混入：纯 [[Co-training|VLM 数据]]（无动作）/ 纯动作数据 / 动作 + 高层语言注释数据。

#### 模块 2: Knowledge insulation via stop-gradient

**设计动机**：纯 frozen backbone → 缺机器人 representation；纯 joint-training → flow-matching 高方差梯度污染 VLM 语言能力。**只让 backbone 通过稳定的离散 loss 自我更新，action expert 的梯度阻断**。

**具体实现**（attention 层重写）：
- 把 token 划分为 backbone 集合 $X_b$（图像、文本、state、FAST tokens）与 action expert 集合 $X_a$（noisy 连续动作）。
- attention 概率矩阵呈 block 形式 $P=\begin{pmatrix}P_{bb}&0\\P_{ab}&P_{aa}\end{pmatrix}$（backbone 不 attend action expert）。
- 在 $P_{ab}$ 计算 $K_b$ 时套 $\mathrm{sg}(\cdot)$ stop-gradient 算子（公式 5），在 value 聚合时同样套 $\mathrm{sg}(V_b)$（公式 6）。
- 结果：信息**单向**从 VLM 流向 action expert，VLM 完全不知道 action expert 的存在。
- 一个额外好处：action expert 用独立 weights，可以直接把 flow-matching loss 权重 $\alpha = 1$，简化超参。

#### 模块 3: VLM data co-training

**设计动机**：补回 fine-tune 时容易遗忘的 VLM 通用知识。

**具体实现**：generalist 模型训练时混入：
- 图像描述（CapsFusion、COCO）
- VQA（Cambrian-7M、PixMo、VQAv2）
- 物体定位（带 bounding box 的室内场景与家居物品 web 数据）
- 机器人 [[High-level Subtask Prediction|高层 subtask 预测]]

通过公式 4 中的 mask $M^{\ell}$ / $M^{\text{act}}$ 控制每个样本走哪一路 loss。

## 关键公式

### 公式 1: [[VLA|VLA 模型一般形式]]

$$
\pi_\theta(y \mid I_{1:V}, q, \ell) = p\Big(y_{1:n}\,\Big|\,f_\theta\big((\phi_{\rho(i)}(x_i))_{i=1}^n,\,A((\rho(i))_{i=1}^n),\,(\rho(i))_{i=1}^n\big)\Big)
$$

**含义**：把多模态输入嵌入后通过带 attention mask $A$ 的 transformer $f_\theta$，输出动作 / 文本 token 的分布。

**符号说明**：
- $x_i$：第 $i$ 个 token（图像 patch、文本、动作或 state）
- $\rho(i) \in \{\text{image}, \text{word}, \text{action}, \text{state}, \dots\}$：模态类型函数
- $\phi_{\rho(i)}$：模态对应的 embedding 函数
- $A \in \{-\infty, 0\}^{n\times n}$：attention mask
- $f_\theta$：transformer 主体（可能是 [[Mixture of Experts|MoE]]）

### 公式 2: [[Cross Entropy Loss|AR-VLA 自回归损失]]

$$
\mathcal{L}_{\text{AR-VLA}}(\theta) = \mathbb{E}_{(x,y) \sim \mathcal{D}}\Bigg[-\sum_{j=1}^{n-1} M_j \log p_\theta(y_{j+1} \mid x_{1:j})\Bigg]
$$

**含义**：标准下一 token 预测的 cross-entropy，$M_j$ 决定哪些位置参与监督。

**符号说明**：
- $\mathcal{D}$：数据集
- $M_j \in \{0, 1\}$：loss mask
- $p_\theta(y_{j+1} \mid x_{1:j})$：下一 token 概率

### 公式 3: [[Flow Matching|FLOW-VLA 损失]]

$$
\mathcal{L}_{\text{FLOW-VLA}}(\theta) = \mathbb{E}_{\mathcal{D}, \tau, \omega}\Big[\big\|\omega - a_{1:H} - f^a(a_{1:H}^{\tau,\omega})\big\|^2\Big]
$$

其中 noised 动作 $a_{1:H}^{\tau,\omega} = \tau a_{1:H} + (1 - \tau)\omega$，$\omega \sim \mathcal{N}(0, \mathbf{I})$。

**含义**：flow matching 让 action expert $f^a$ 预测从噪声到真实动作的速度场 $\omega - a_{1:H}$。

**符号说明**：
- $\tau \in [0, 1]$：flow 时间索引，按 $\mathrm{Beta}((s-\tau)/s; 1.5, 1)$，$s=0.999$ 采样（偏向小 $\tau$）
- $\omega$：高斯噪声
- $a_{1:H}$：真实连续动作 chunk（$H=50$）

### 公式 4: [[Knowledge Insulation|CO-VLA 联合损失]]

$$
\mathcal{L}_{\text{CO-VLA}}(\theta) = \mathbb{E}_{\mathcal{D}, \tau, \omega}\Bigg[-\sum_{j=1}^{n-1} M_j^{\ell} \log p_\theta(\hat{\ell}_{j+1} \mid x_{1:j}) + \alpha\, M^{\text{act}} \big\|\omega - a_{1:H} - f_\theta^a(a_{1:H}^{\tau,\omega})\big\|^2\Bigg]
$$

**含义**：把 AR 离散 loss（含语言 token 与 [[FAST Token|FAST 动作 token]]）和 flow-matching 连续动作 loss 加权混合，可灵活混入纯 VLM 数据 / 动作数据 / VLM+动作数据。

**符号说明**：
- $M^{\ell} \in \{0, 1\}^{n}$：语言 / 离散动作 token 的 loss mask
- $M^{\text{act}} \in \{0, 1\}$：该样本是否包含动作预测
- $\alpha$：flow-matching loss 权重；用 stop-gradient 后可设 $\alpha = 1$
- $\hat{\ell}$：包含文本 + FAST 离散动作的混合 token 序列

### 公式 5: [[Stop Gradient|带 stop-gradient 的分块 softmax]]

$$
\begin{pmatrix}P_{bb} & 0 \\ P_{ab} & P_{aa}\end{pmatrix} = \mathrm{softmax}\!\left(\begin{pmatrix}Q_b(X_b)\,K_b(X_b)^T & 0 \\ Q_a(X_a)\,\mathrm{sg}(K_b(X_b)^T) & Q_a(X_a)\,K_a(X_a)^T\end{pmatrix} + A\right)
$$

**含义**：在 attention 的 query×key 矩阵里把 backbone 的 key 套上 $\mathrm{sg}(\cdot)$，使 action expert 计算时能"读"backbone 表示，但梯度不回传。

**符号说明**：
- $X_b, X_a$：backbone / action-expert 处理的 token
- $Q_b, K_b, Q_a, K_a$：各自独立的 Q/K projection
- $\mathrm{sg}(\cdot)$：[[Stop Gradient|stop-gradient]] 算子
- $P_{bb}=0$ 项：backbone 不能 attend action expert

### 公式 6: 隔离后的 value 聚合

$$
E = \begin{pmatrix}E_b \\ E_a\end{pmatrix} = \begin{pmatrix}P_{bb}\,V_b(X_b) \\ P_{ab}\,\mathrm{sg}\!\big(V_b(X_b)\big) + P_{aa}\,V_a(X_a)\end{pmatrix}
$$

**含义**：action expert 端聚合 value 时同样对 $V_b$ 套 stop-gradient，确保完整切断梯度。最终 $\mathrm{attn}(X) = PE$。

**符号说明**：
- $V_b, V_a$：backbone / action expert 的 value projection
- $E_b, E_a$：各自的输出 embedding

### 公式 7: [[Flow Matching|时间步采样]]

$$
p(\tau) = \mathrm{Beta}\!\left(\frac{s - \tau}{s};\ \alpha = 1.5,\ \beta = 1\right),\ s = 0.999
$$

**含义**：偏向小 $\tau$（更接近噪声端）采样，沿用 [[Pi0]] 的设计；与均匀采样或中段加权（如 SD3）不同。

**符号说明**：
- $\tau \in [0, 1]$：flow 时间步
- $s = 0.999$：避免数值奇异的截断

## 实验

### 数据集

| 数据集 | 规模 | 特点 | 用途 |

| [[DROID]] | 真实 tabletop | 跨环境 / 跨物体 benchmark | 生 generalist 评测 |

### 实现细节

- **Backbone**: [[PaliGemma]] 2B，{width 2048, depth 18, mlp_dim 16384, num_heads 18, num_kv_heads 1, head_dim 256}
- **[[Action Expert]]**: 同 depth，{width 1024, mlp_dim 4096}，约 300M 参数
- **Action horizon**: $H=50$
- **noisy 动作输入**：先线性投影到 transformer embedding 维度
- **timestep 注入**：[[Sinusoidal Positional Encoding|sinusoidal]] $\phi(\tau)$ → 双层 swish MLP → [[Adaptive RMSNorm]] 注入到 action expert 每层
- **attention prefix mask**：图像 / 文本 / text state 用 full prefix；FAST 动作 token 自回归地 attend 自身和 prefix；action-expert 连续 token attend prefix 与彼此但**不 attend FAST tokens**
- **timestep 分布**：$\mathrm{Beta}((s-\tau)/s; 1.5, 1)$, $s=0.999$（偏小 $\tau$）
- **flow loss 权重**：$\alpha = 1$（stop-gradient 让其不冲突）
- **训练成本**：相对纯 flow matching 增加约 20%，但因收敛快 7.5×，wall-clock 仍快于 [[Pi0]]

### 关键实验结论

1. **Performance**：在 7 项真实任务 + LIBERO 上全面领先 [[Pi0]]、[[Pi0-FAST]]、[[HybridVLA]]、[[OpenVLA-OFT]]、[[Transfusion]]。
2. **Knowledge insulation**：去掉 stop-gradient 后[[Language Following|语言遵循]]立刻崩，证明梯度污染是真实存在的（Fig 4b、Fig 6a）。
3. **Language following**：stop-gradient 与 VLM data co-training 都各自能改善语言遵循；二者叠加最强。
4. **Convergence speed**：与 [[Pi0-FAST]] 相当；[[Pi0]] 需要 7.5× 训练步数。
5. **Generalization**：VLM data co-training 对 OOD 物体语义泛化至关重要（Fig 7）。
6. **State representation ablation**：KI 对 text state 与 continuous state 都鲁棒，[[Pi0]] 不行。
7. **Naive vs FAST tokenization**：naive token 也比纯 flow matching 强，但 FAST 更优；naive + stride-5 子采样比稠密 naive 更强（token 越少 representation 信号越聚焦）。
8. **DROID 真实泛化**：本方法 0.55 ± 0.09 > [[Pi0]] 0.49 > [[Pi0-FAST]] 0.45。

## 批判性思考

### 优点

1. **理论简洁**：用 stop-gradient 这种"近乎免费"的工程改动直接解释并解决"梯度污染"问题，干净有解释力。
2. **机制可拆解**：stop-gradient、joint discrete/continuous、VLM co-training 三个 component 互相 ablation 清楚（Fig 4–6），不像很多工程系统是一锅端。
3. **训练慢的痛点直接缓解**：7.5× 收敛加速对工业部署是实打实的成本节省。
4. **"训练快+推理快+泛化强"三角达成**：这是 VLA 领域第一个明确同时拿下三个目标的 recipe。
5. **后续工作快速吸收**：π0.6、π0.7 都把 KI 当成默认配置，证实其工程鲁棒性。

### 局限性

1. **Long-horizon 任务还是输 [[OpenVLA-OFT]]**：LIBERO-10 / LIBERO-Long 上本方法 85.8，OpenVLA-OFT 94.5。意味着对**长序列依赖**的拟合还有缺口，作者也承认这点。
2. **训练成本增加 ~20%**：虽然 wall-clock 仍快，但 per-step 算力多 20%，小团队复现成本不低。
3. **方法没有正式名字**：论文标题里只有"Knowledge Insulation"作为 recipe 名，没有像 [[Pi0]] 那种独立模型代号，引用与对比时容易混淆（社区一般称 "KI" 或 "π0-KI"）。
4. **[[FAST Token]] 的依赖**：好结果依赖 FAST tokenizer 提供的"压缩离散动作"信号；naive tokenization 退化（Fig 5），这意味着 KI 与 FAST 紧绑定。
5. **缺 sim-to-real / safety 角度的分析**：所有评测都是真机或 LIBERO，对 sim-to-real gap、failure mode 的系统分析较少。

### 潜在改进方向

1. **更弱的 representation 监督**：能否不依赖 FAST，而是用 [[Diffusion Policy|diffusion-based]] 或 [[VQ-VAE]] 等动作 tokenizer 提供更具表达力的离散监督？
2. **可学习的 stop-gradient 强度**：完全切断 vs 不切断之间是否存在中间档（如 gradient scaling λ ∈ (0,1)），可能进一步平衡 representation 学习与稳定性。
3. **长程任务结构**：把 [[High-level Subtask Prediction|高层 subtask 预测]] 作为 KI 的第三条 head（而非只作为 co-training 数据），可能改善 LIBERO-Long 弱点。
4. **scaling**：现 backbone 仅 2B，更大 VLM（如 [[Gemma|Gemma 3 4B]]，已在 [[Pi06]] 中使用）下知识隔离的边际收益尚未充分研究。
