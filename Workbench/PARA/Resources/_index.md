## System boundaries

- MindFlow 负责研究解读、分类和知识关联。
- 官方论文、出版社、arXiv 与 DOI registry 负责论文事实。
- Zotero 负责本地 library membership、item keys 和附件。
- 本索引不复制知识正文，也不镜像 Zotero collection tree。
