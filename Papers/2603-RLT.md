## 一句话总结

> 在冻结的 [[Flow Matching VLA\|VLA]] 里加一个 **RL Token** 把内部表示压成 2048 维向量，用它喂给一对极小的 actor-critic，用 **chunked 离散动作 + 参考动作正则**，**几小时**真机训练就把拧螺丝、绑扎带、网线/充电器插接这些"最后一毫米"任务的吞吐量提升最高 3 倍。

---

## 核心贡献

1. **[[RL Token]]**: 在预训练 [[Flow Matching VLA\|VLA]] 的 token 序列里追加一个 learned readout embedding `<rl>`，用一个轻量 [[Encoder-Decoder Transformer\|encoder-decoder transformer]] 训练它去自重建 VLA 内部所有 token，从而把高维 VLA features **压缩成单个 2048 维向量** $\mathbf{z}_{\text{rl}}$ 作为 RL 状态表示。冻结 VLA 后，online RL 只需在这个紧凑向量上做。
2. **基于 [[Action Chunking\|动作块]] 的 [[Off-policy Actor-Critic\|off-policy actor-critic]]**: actor 输出 $C$ 步动作块（$C{=}10$），把稀疏奖励的有效 horizon 缩短到 $H/C$，[[TD3]] 风格的 critic 用 $C$-step return 做 TD backup。这是目前在 VLA 上做 online RL **真正能 scale** 的关键。
3. **[[Reference-Action Pass-Through\|Reference-Action Pass-Through]] + [[Reference Action Dropout\|Dropout]] 正则**: actor 把 VLA 推理出的参考动作块 $\bar{\mathbf{a}}_{1:C}$ 也作为输入，loss 里同时加 $\beta\|\mathbf{a}-\bar{\mathbf{a}}\|_2^2$ 把它锚住，再用 50% dropout 防止 actor 退化为"纯抄"。把 online RL 变成对 VLA 提议的 **局部精修**，避开高维动作空间的盲目探索。
4. **真机 4 任务 + 5 个 baseline 全面验证**: 在 **screw installation / zip tie / Ethernet / charger** 四个亚毫米精度任务上，相比 [[Pi06 Base Model\|π0.6]] 基础策略，吞吐量最多 $3\times$、关键阶段成功率从 20% → 65%；对 [[HG-DAgger\|DAgger]] / [[ConRFT\|HIL-SERL]] / `PLD` / [[DSRL]] 4 个 baseline 都显著领先。Ethernet 任务的最终 RL 策略 **甚至比专家遥操作还快**（中位 episode 长度 66 vs 146 timesteps）。

## 问题背景

### 要解决的问题

通用 [[VLA]] 模型靠演示数据学到了广泛技能，但在 **"最后一毫米"** 的精密接触阶段（拧螺丝、插网线、绑扎带）经常失败：
- 演示数据里这种亚毫米对齐就是最难标的，覆盖率天然不够；
- 真实机器人运行带噪声、有磨损，部署时小误差会复合成失败；
- 最自然的修复是直接对目标任务做 **online RL** 练几小时，但怎么练才高效？

### 现有方法的局限

| 路线               | 代表                                        | 局限                                                                      |
| ---------------- | ----------------------------------------- | ----------------------------------------------------------------------- |
| 全模型 RL fine-tune | [[Recap]], [[SimpleVLA-RL]], DPPO         | 上百亿参数都在更新，**算力 + 样本都贵**，在线难 scale                                       |
| 单步残差/动作头 RL      | `PLD`, [[Steering VLA]] (ATE), [[ConRFT]] | 单步动作 $\Rightarrow$ 有效 horizon 极长，[[Sparse Binary Reward\|稀疏二值奖励]] 信用分配崩 |
| 噪声空间 RL          | [[DSRL]]                                  | 只在 [[Flow Matching\|flow]] 模型噪声空间搜，**仍受限于 VLA 已能产生的动作分布**               |
| 小模型 RL + 演示      | [[ConRFT\|HIL-SERL]], RL-100              | encoder 是 ImageNet ResNet，**丢掉了 VLA 预训练里的语义先验**                         |
| 模仿学习 + 干预        | [[HG-DAgger\|DAgger]]                     | 受限于人类演示速度，无法超越教师                                                        |

核心矛盾：**VLA 的语义先验** 与 **轻量 RL 的高效样本利用** 没有桥接好。

### 本文的动机

让 VLA 当 "[[Behavior Policy\|reference policy]] + 感知特征提取器"，但**只把动作重精修这件事**交给一个能跑得起 online RL 的轻量 actor-critic。为此需要：
1. 一个 **紧凑、任务相关** 的状态表示 → [[RL Token]]；
2. 一个能用 **chunked 动作** 做 TD 学习的 off-policy 算法 → 改造 [[TD3]]；
3. 一个把 actor 锁在 VLA 提议附近的正则化机制 → [[Reference-Action Pass-Through]]。

## 方法详解

### 模型架构

RLT 在冻结的 [[Pi06 Base Model\|π0.6]] [[VLA]] 之上增加两个外挂模块：**RL token 提取器** 和 **轻量 actor-critic**。

- **输入**:
  - 视觉 $\mathbf{X}^i_t$：4 路相机（双 wrist + base，共 1500–6000 控制步级别的真实数据流）
  - 语言指令 $\ell$（如 `"insert screw"`，每个任务固定一句）
  - [[Proprioceptive State\|本体感觉]] $\mathbf{s}^p_t$（关节角 / 末端位姿 / gripper，14 维）
- **VLA 主干**: [[Pi06 Base Model\|π0.6]] = pre-trained [[Vision Encoder\|SigLIP]] (400M) + [[Gemma]] (4B) + [[Action Expert]] (860M)
- **新增 RL token 提取器**: encoder–decoder [[Transformer]] $g_\phi / d_\phi$，用一个 learned readout embedding $\mathbf{e}_{\text{rl}} = \mathbf{e}_\phi(\texttt{<rl>})$ 从 VLA 的 final-layer token 向量 $\mathbf{z} = f(s, \ell; \theta_{\text{vla}})$ 中萃取出 $\mathbf{z}_{\text{rl}} \in \mathbb{R}^{2048}$
- **轻量 actor**: $\pi_\theta(\mathbf{a}_{1:C} | \mathbf{x}, \bar{\mathbf{a}}_{1:C}) = \mathcal{N}(\mu_\theta(\mathbf{x}, \bar{\mathbf{a}}_{1:C}), \sigma^2 \mathbf{I})$，2 层 MLP 隐层 256（或 3 层 512 用于 screw installation），输出 $C{=}10$ 步动作块；输入是 $\mathbf{x} = (\mathbf{z}_{\text{rl}}, \mathbf{s}^p)$ + VLA 给出的参考动作块 $\bar{\mathbf{a}}_{1:C}$
- **轻量 critic**: $Q_\psi(\mathbf{x}, \mathbf{a}_{1:C}) \in \mathbb{R}$，用 [[TD3]] 风格的双 Q ensemble 取 min；输入同 actor，但接收 actor 真正执行的 $\mathbf{a}_{1:C}$
- **输出**: 由 actor 直接产生的 chunked 动作 $\mathbf{a}_{t:t+C-1}$，控制频率 50 Hz，每个 chunk 对应 0.2 秒

整体逻辑见 Fig 1：左侧 "VLA with RL Token" 输出 token + 参考动作，右侧 actor-critic 在它之上做 online RL 改进。

### 核心模块

#### 模块 1: [[RL Token]] 抽取（自重建预训练）

**设计动机**: 直接拿 VLA 的所有 token 给 RL 用就太大了；ResNet 之类的通用 encoder 又丢了 VLA 的先验。理想表示要 **紧凑**（一个向量）+ **任务相关**（保住 VLA 内部知识）。

**具体实现**:
- 在 VLA 输入序列末尾追加一个特殊 token `<rl>`，对应 learned embedding $\mathbf{e}_{\text{rl}}$
- 一个轻量 encoder transformer $g_\phi$ 处理 `[VLA 各层 token, e_rl]`，最后取 `<rl>` 位置的输出作为 $\mathbf{z}_{\text{rl}}$
- 一个 decoder transformer $d_\phi$ + 线性 head $h_\phi$ 从 $\mathbf{z}_{\text{rl}}$ 自回归地 **重建 VLA 内部所有 stop-grad token**，迫使 $\mathbf{z}_{\text{rl}}$ 当瓶颈
- 在小规模 task-specific demonstration 上训 2000–10000 step；可选地把 VLA 也微调一下（loss 里加权重 $\alpha \mathcal{L}_{\text{vla}}$）

#### 模块 2: [[Off-policy Actor-Critic]] over [[Action Chunking\|Action Chunks]]

**设计动机**: VLA 控制频率 50 Hz，单步动作 RL 的有效 horizon 是几千步，[[Sparse Binary Reward\|稀疏奖励]] 根本传不过去。Chunk 起来 horizon 缩到 $H/C$。

**具体实现**:
- **Critic 训练（[[TD3]]-style）**: 用 [[Replay Buffer]] $\mathcal{B}$ 的 transitions $(\mathbf{x}, \mathbf{a}_{1:C}, \mathbf{x}')$，目标用 $C$-step 累计奖励：
  - $\hat{Q} = \sum_{t'=1}^{C} \gamma^{t'-1} r_{t'} + \gamma^C \mathbb{E}_{\mathbf{a}' \sim \pi_\theta}[Q_{\psi'}(\mathbf{x}', \mathbf{a}')]$
  - 双 Q ensemble + target network ($\psi'$)；2 critic update : 1 actor update；Update-to-Data ratio = 5
- **Subsampling Action Chunks**: 每秒 50 Hz × 1 秒 chunk 起步太稀，作者用 stride 2 把 $\langle \mathbf{x}_0, \mathbf{a}_{0:C} \rangle, \langle \mathbf{x}_2, \mathbf{a}_{2:C+2} \rangle, \ldots$ 都存进 buffer，**每秒能产 25 个训练样本**

#### 模块 3: [[Reference-Action Pass-Through]] + [[Reference Action Dropout]]

**设计动机**: 直接在高维 chunked 动作空间做无约束探索会把 VLA 先验 "学糊"；又不能纯抄 VLA 否则没改进。

**具体实现**:
- actor 输入里加 VLA 的参考动作块 $\bar{\mathbf{a}}_{1:C}$（pass-through）
- loss 里加 BC 正则 $\beta \|\mathbf{a}_{1:C} - \bar{\mathbf{a}}_{1:C}\|_2^2$（默认 $\beta$ 较大）
- **Reference Action Dropout**: 训练时随机 50% 的样本把 $\bar{\mathbf{a}}_{1:C}$ 置零，强迫 actor 维持独立的动作生成能力，避免 "全靠抄"
- 推理时永远提供 $\bar{\mathbf{a}}_{1:C}$，actor 学到何时偏离它（critic 信号大）、何时跟从它（critic 信号小）

#### 模块 4: 关键阶段（critical phase）+ 全任务两段式训练

**设计动机**: 一个任务里只有插入/拧紧的最后几秒最难，RL 应该集中练那段。

**具体实现**:
- 数据采集时 human 操作员决定何时把控制权从 VLA 切给 RL actor（imitation 风格）
- 仅对 critical phase 收集 transitions 训 RL，其它阶段用 base VLA 走
- 训完关键阶段后再把 RL 扩到 full task；测试时用人工干预记录学一个二分类 switch policy 自动切换

## 关键公式

### 公式 1: [[RL Token]] 提取

$$
\mathbf{z}_{\text{rl}} = g_\phi\!\left([\mathbf{z}_{1:M}, \mathbf{e}_{\text{rl}}]\right)_{M+1}
$$

**含义**: encoder transformer $g_\phi$ 在 VLA token 序列尾部追加 readout embedding $\mathbf{e}_{\text{rl}}$，取最后一个位置的输出作为 RL token。

**符号说明**:
- $\mathbf{z}_{1:M} = \{\mathbf{z}_1, \ldots, \mathbf{z}_M\}$: 预训练 VLA 的 final-layer 各 token 嵌入
- $\mathbf{e}_{\text{rl}}$: 可学习 readout embedding，对应特殊 token `<rl>`
- $g_\phi$: 轻量 encoder transformer
- $\mathbf{z}_{\text{rl}} \in \mathbb{R}^{2048}$: 压缩后的 RL 状态表示

### 公式 2: [[RL Token]] 自重建损失

$$
\mathcal{L}_{\text{ro}} = \mathbb{E}_{\mathcal{D}}\!\left[\sum_{i=1}^{M} \big\| h_\phi\!\left(d_\phi([\mathbf{z}_{\text{rl}}, \bar{\mathbf{z}}_{1:i-1}])\right)_i - \bar{\mathbf{z}}_i \big\|^2\right]
$$

**含义**: 强迫从 $\mathbf{z}_{\text{rl}}$（信息瓶颈）能自回归重建出 VLA 所有内部 token，确保 RL token 保留任务相关知识。

**符号说明**:
- $\mathcal{D}$: small task-specific demonstration dataset
- $d_\phi$: decoder transformer（自回归）
- $h_\phi$: 线性输出投影
- $\bar{\mathbf{z}}_i = \texttt{sg}(\mathbf{z}_i)$: VLA token 的 [[Stop Gradient\|stop-gradient]] 版本（保证 VLA 主干被冻结）
- 训练时通常配 $\theta_{\text{vla}}$ 的小幅微调，目标变成 $\arg\min_{\phi, \theta_{\text{vla}}} \mathcal{L}_{\text{ro}}(\phi) + \alpha \mathcal{L}_{\text{vla}}(\theta_{\text{vla}})$

### 公式 3: Critic 训练（[[TD3]] 风格 [[Off-policy Actor-Critic\|off-policy]] TD）

$$
\mathcal{L}_Q = \mathbb{E}_{(\mathbf{x}, \mathbf{a}_{1:C}, \mathbf{x}') \sim \mathcal{B}}\!\left[\big(\hat{Q} - Q_\psi(\mathbf{x}, \mathbf{a}_{1:C})\big)^2\right]
$$

$$
\hat{Q} = \sum_{t'=1}^{C} \gamma^{t'-1} r_{t'} + \gamma^C \mathbb{E}_{\mathbf{a}' \sim \pi_\theta}\!\left[Q_{\psi'}(\mathbf{x}', \mathbf{a}')\right]
$$

**含义**: 标准 off-policy [[TD3]]，但 reward 用 $C$-step 累积、bootstrap 用 $\gamma^C$ 折扣的 target Q，使 [[Sparse Binary Reward\|稀疏二值奖励]] 在长 horizon 下也能传播。

**符号说明**:
- $\mathcal{B}$: [[Replay Buffer]]，混合 VLA warmup rollout + RL rollout + 人工干预
- $\mathbf{x} = (\mathbf{z}_{\text{rl}}, \mathbf{s}^p)$: actor/critic 共享的状态
- $\mathbf{x}'$: 下一个状态（chunk 末端 + 重新算的 RL token）
- $\psi'$: target network 参数
- $C{=}10$: 默认 chunk 长度（screw installation 等任务）

### 公式 4: Actor 高斯策略

$$
\pi_\theta(\mathbf{a}_{1:C} | \mathbf{x}, \bar{\mathbf{a}}_{1:C}) = \mathcal{N}\!\left(\mu_\theta(\mathbf{x}, \bar{\mathbf{a}}_{1:C}), \sigma^2 \mathbf{I}\right)
$$

**含义**: actor 是各向同性高斯，均值由 MLP 给，方差固定（小标准差）。条件里同时含状态和 VLA 参考动作 → reference-action pass-through。

**符号说明**:
- $\bar{\mathbf{a}}_{1:C} \sim \pi_{\text{vla}}(\cdot | s, \ell)$: VLA 在每个 chunk 边界采样的 reference action chunk
- $\sigma$: 固定标准差（小，鼓励在参考附近探索）

### 公式 5: Actor 损失（Q 提升 + BC 正则）

$$
\mathcal{L}_\pi(\theta) = \mathbb{E}_{\substack{\mathbf{s} \sim \mathcal{B} \\ \mathbf{a}_{1:C} \sim \pi_\theta}}\!\left[ -Q_\psi(\mathbf{x}, \mathbf{a}_{1:C}) + \beta \big\|\mathbf{a}_{1:C} - \bar{\mathbf{a}}_{1:C}\big\|_2^2 \right], \quad \bar{\mathbf{a}}_{1:C} \sim \pi_{\text{vla}}(\cdot | \mathbf{s}, \ell)
$$

**含义**: actor 同时最大化 critic 估值 + 把动作锁在 VLA 参考附近，把 online RL 转成 "VLA 提议 + 局部精修"。

**符号说明**:
- $\beta$: 正则强度（消融显示 $\beta{=}0$ 性能掉得最猛，是单点最关键的超参）
- BC 正则项 + reference-action dropout 共同防退化为纯模仿
- 梯度只流到 $\theta$（actor 参数），VLA 的 $\bar{\mathbf{a}}_{1:C}$ 不回传

## 算法 1: RLT 完整训练流程

> 直接对应论文 Algorithm 1，把整个系统讲完。

**Require**: 冻结的 VLA backbone $f_{\theta_{\text{vla}}}$、VLA 动作分布 $\pi_{\text{vla}}$、演示集 $\mathcal{D}$、chunk 长 $C$、buffer $\mathcal{B}$、warmup 步数 $N_{\text{warm}}$、UTD 比 $G$、VLA fine-tune 权重 $\alpha$、policy 约束 $\beta$

1. **训练 RL token（可选地微调 VLA）**: 在 $\mathcal{D}$ 上最小化 $\mathcal{L}_{\text{ro}}(\phi) + \alpha \mathcal{L}_{\text{vla}}(\theta_{\text{vla}})$，得到 $\phi, \theta_{\text{vla}}$
2. **训练 RL actor 和 critic**:
   - 初始化 $Q_\psi, \pi_\theta$
   - **for** environment step $t = 0, C, 2C, \ldots$:
     1. 采样 VLA 参考 $\bar{\mathbf{a}}_{t:t+C-1} \sim \pi_{\text{vla}}(\mathbf{s}_t)$
     2. 形成 RL state $\mathbf{x}_t = (\mathbf{z}_{\text{rl}}(\mathbf{s}_t), \mathbf{s}^p_t)$
     3. 选动作：人工干预时用 $\mathbf{a}^{\text{human}}$；warmup 期用 VLA 参考；否则 $\sim \pi_\theta$
     4. 执行并观察 $r_t, \mathbf{s}_{t+1}, \mathbf{s}^p_{t+1}$
     5. 若有人工干预，把 transition 里的 reference 也覆盖为 $\mathbf{a}^{\text{human}}$
     6. 把 $\langle \mathbf{x}_t, \mathbf{a}_{t:t+C-1}, \bar{\mathbf{a}}, r_t, \mathbf{x}_{t+1} \rangle$ 存入 $\mathcal{B}$（含 stride=2 的子 chunk）
     7. **for** $g = 1, \ldots, G$:
        - 采 batch $b \sim \mathcal{B}$；按 Eq. 3 算 $\hat{Q}$；用 Eq. 3 训 critic；用 Eq. 5 训 actor

### Table 2: 消融实验（Ethernet 关键阶段，从 Fig 7–8 提炼）

| 配置 | 训练后 throughput | 训练后 success | 影响分析 |
|------|------------------|----------------|---------|
| w/o RL Token (用 ResNet-10) | ~50% of full | 与 RLT 接近 | VLA 表示比 ImageNet encoder 更管用 |
| w/o Chunk ($C{=}1$) | 接近 0 | 接近 0 | 50 Hz 单步动作下信用分配崩，VLA 调用频率也不可行 |

## 实验

### 数据集

| 数据集 | 规模 | 特点 | 用途 |
|--------|------|------|------|
| 任务专属演示 | 1–10 小时 / 任务 | 真机 [[HG-DAgger\|teleop]] 演示 | 训练 RL token (2k–10k 梯度步) + 微调 VLA |
| Online rollouts | 400–1000 episodes | 含人工干预的 RL 收集 | 关键阶段约 5 分钟 ~ 1 小时；全任务最多 5 小时 |

### 实现细节

- **Backbone**: [[Pi06 Base Model\|π0.6]] (5.26B 参数：[[Vision Encoder\|SigLIP]] 400M + [[Gemma]] 4B + [[Action Expert]] 860M)
- **RL Token 维度**: 2048
- **Actor**: 2 层 MLP hidden 256（Ethernet/charger/zip tie），3 层 hidden 512（screw）；高斯策略，固定 std
- **Critic**: 2-Q ensemble, target network, 取双 Q min（[[TD3]]）
- **Action chunk 长度** $C$: 10
- **控制频率**: 50 Hz（动作维度 14 → chunked action 维度 140）
- **Subsampling stride**: 2（每秒约 25 个训练样本入 buffer）
- **UTD ratio**: 5（critic 2 次 / actor 1 次）
- **BC 正则强度** $\beta$: 较大（论文未给精确值，消融显示去掉时性能崩）
- **Reference action dropout**: 50%
- **Sparse reward**: 仅在任务完成时由人类按下 +1
- **Warmup**: 用 VLA rollout 预填 buffer 数百 episode 后再启动 actor 学习

### 训练成本

总实验时长（含 reset/各类失败）每个任务 15 分钟 ~ 5 小时真机数据；完成 RL 训练后还可对 VLA 做一次短期 SFT，把 RL 策略 distill 回 VLA，便于 test 时自动切换。

### 可视化结果

- 在 Ethernet 任务上，base [[Pi06 Base Model\|π0.6]] 经常在端口附近 "试探-退回-再试"；RLT 学到 **顺势流畅插入**，第一次失败时还会施压并轻微摇动连接器借助力柔顺完成插入。
- 在 screw 任务上，base 经常 grip 偏一点点就把螺丝顶歪；RLT 学到先轻压再加力，避免螺丝弹跳。

## 批判性思考

### 优点

1. **工程上极轻量**：5.26B [[VLA]] 完全冻结，只更新一个 ~M 级 MLP，单卡就能 online 训。
2. **chunked + 二值 reward + BC 正则** 三件套是实用的 real-world RL 配方，迁移性强。
3. **Reference Action Dropout** 是简洁有力的 trick，避免 conditioning collapse 问题。
4. **真机实验扎实**：4 任务 × 5 baseline，含吞吐 / 成功率 / 速度直方图三类指标，论据充分。
5. RL 学到的策略 **可以超越 teleop 速度**（Fig 9 中位 66 vs 146），这是 imitation 类方法永远做不到的。

### 局限性

1. **依赖人工干预与人工奖励信号**：每个 episode 末由人按按钮判定成败，人工干预也参与训练；做 fully autonomous pipeline 需要再加 reward model 与进度估计。
2. **任务粒度局限于 critical phase**：full-task setting 的成功率比 critical-phase setting 低不少（screw 50% vs 50%、zip tie 85% vs 85% 仅在关键阶段；full task 上 base + RL 整体仍受前序 grasp/transport 影响）。
3. **每任务一个 RL token + actor + critic**：跨任务复用是否能 share 参数没讨论；RL token 是否对 multi-task generalization 有帮助仍是开问题。
4. **Reward 极稀疏**：只有 1/0 终局信号，对长 horizon 仍依赖 chunk 缩短 horizon + 人工干预提供多 demo，不易迁移到难以人为判断的任务。
5. **没有 arXiv / 开源代码**（截至发布只看到 PI 官网 PDF）：复现门槛高。

### 潜在改进方向

1. **自监督进度预测** 替代人工奖励（与 [[Recap]] 的 distributional value function 结合）。
2. **多任务 RL token**：用一个 readout token + meta-learned $g_\phi$ 在 task family 上预训练，减少每个新任务的 demonstration 需求。
3. **延续到 full-task autonomy**：把 critical-phase RL 的优势 distill 回 base VLA，以避免运行时切换策略。
4. **结合 [[DSRL]] 的噪声空间探索**：在 RL token 状态下做 latent noise 调制，把 mode-aware 探索引入 chunked actor。
5. **scaling laws**：当前演示量 1–10 小时、训练时长几小时，规模再扩 10× 后的性能曲线是否还线性？

### 可复现性评估

- [ ] 代码开源（暂无）
- [ ] 预训练模型（[[Pi06 Base Model\|π0.6]] 部分公开 model card，但 RL token / actor / critic 没放）
